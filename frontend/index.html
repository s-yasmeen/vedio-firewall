Two-sided task-aware control

The doctor requests the task. The patient firewall controls the disclosure.

TAPF-MIN binds each clinical request to a purpose, recipient, session and patient authorization. It then selects the minimum authorized representation, tests identity leakage including repeated exposure, verifies task utility, and fails closed when any condition is not satisfied.
